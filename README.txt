ШИФРОВАНИЕ КОНТРАГЕНТОВ — программа с окном для Windows и macOS
=================================================================

ЧТО ДЕЛАЕТ
• По словарю (столбец A — настоящее название, B — шифр) заменяет значения
  в столбце «Контрагент» на всех листах Excel-файла — в одну или другую сторону.
• По умолчанию сохраняет результат рядом, в новый файл
  (data_зашифровано.xlsx / data_расшифровано.xlsx), исходник не трогает.
• Показывает, сколько заменено на каждом листе и каких контрагентов нет в словаре.
• Предупреждает о дублях в словаре и о том, что файл открыт в Excel.

КАК ПОЛЬЗОВАТЬСЯ
1. Запустить программу.
2. «Выбрать…» — словарь, «Выбрать…» — файл с данными.
3. Нажать «Зашифровать» или «Расшифровать».

ЗАПУСК БЕЗ СБОРКИ (если на компьютере есть Python 3.9+)
  pip install openpyxl
  python kontragent_shifr.py        (на Mac: python3 kontragent_shifr.py)

СБОРКА В ОБЫЧНУЮ ПРОГРАММУ (чтобы у пользователей Python не требовался)
Собирать нужно на той ОС, для которой программа:
• Windows: установить Python с python.org (галочка «Add Python to PATH»),
  дважды щёлкнуть build_windows.bat → dist\Shifr_kontragentov.exe
• macOS: в Терминале  bash build_mac.sh  → dist/Shifr_kontragentov.app
  Первый запуск на чужом Mac: правой кнопкой по программе → «Открыть»
  (программа не подписана сертификатом Apple).

Вариант без своих компьютеров: загрузить папку в репозиторий GitHub —
файл .github/workflows/build.yml сам соберёт .exe и Mac-версию
(вкладка Actions → последний запуск → Artifacts).

Антивирус Windows иногда настороженно относится к .exe от PyInstaller —
при необходимости добавьте программу в исключения.
